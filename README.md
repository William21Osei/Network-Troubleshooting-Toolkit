
# Network Troubleshooting Toolkit

A Python command-line tool for practicing basic network troubleshooting.

## Features

- DNS hostname resolution
- TCP connectivity test on HTTPS port 443
- Connection timeout handling
- Clear pass/fail results
- Timestamped test session

## Requirements

- Python 3.9 or later
- A network connection for external hostname tests

## Run the Program

```bash
python network_toolkit.py
```

Enter a hostname such as `example.com` when prompted.

## Concepts Demonstrated

- Python functions
- Exception handling
- Socket programming
- DNS resolution
- TCP connections
- Input validation

## Limitations

A failed test does not necessarily mean the whole network is down. DNS settings, firewalls, proxies, and remote server restrictions can affect the result. This tool does not scan networks or repair connectivity problems.
